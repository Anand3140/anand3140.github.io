⭐ Flagship
Omex DG Controller

The complete AMF/DG automation controller. Monitors mains power, auto-starts diesel generators on failure, manages contactors, and reports everything live over GSM/MQTT — built on STM32F401 with fully custom firmware.

  • Automatic mains failure detection and DG start sequence
  • 3-phase voltage, frequency & current monitoring
  • GSM/MQTT cloud reporting with full event history
  • EEPROM-persistent config with IWDG watchdog protection
  • Remote manual/auto mode switching via mobile app
  • Battery health monitoring with ADC rolling average filter
