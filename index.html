⭐ Flagship Product
Omex DG Controller

The flagship AMF/DG automation controller. Monitors 3-phase mains power, auto-starts diesel generators on failure, manages contactors, and reports everything live to the cloud over GSM/MQTT. Built on STM32F401 with custom firmware — fully field-proven.

  • Automatic Mains Failure detection and DG start sequence
  • 3-phase voltage, frequency & current monitoring
  • GSM/MQTT cloud reporting with event history
  • EEPROM-persistent config, IWDG watchdog protection
  • Remote manual/auto mode switching via mobile app
  • Battery health monitoring with ADC & rolling average filter
IoT Platform
Omex IoT Monitor

Cloud-connected monitoring platform. Real-time device telemetry, alarm management, event logs, and dashboards — accessible from any browser or mobile device.

  • Firebase real-time database integration
  • Push alerts for critical events
  • Historical data charts & export
  • Multi-device management panel
AI System
Face Attendance

AI-powered face recognition attendance system for schools and offices. Camera-based, anti-spoofing enabled, with sub-second recognition and cloud sync.

  • ArcFace / InsightFace recognition engine
  • Anti-spoofing (liveness detection)
  • pgvector cosine similarity matching
  • Web dashboard + mobile sync
